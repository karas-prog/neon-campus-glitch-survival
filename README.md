# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.5.0 — Breathing Edge Lock Fields

Границы атриума больше не статичны. Вокруг игрового пространства закреплены несколько живых цифровых ограждений — **Lock Fields**. Они медленно растут от верхней, нижней и боковых границ, затем сужаются и отступают, создавая постоянно меняющуюся арену.

| Механика | Как работает |
|---|---|
| Покрытие периметра | Шесть сегментов по краям обычно занимают около 35% арены; интенсивность плавно колеблется примерно от 28% до 40% |
| Дыхание | Глубина, длина и положение каждого сегмента меняются по независимым синусоидальным кривым |
| Кривая граница | Внутренний край каждого поля пульсирует волной, показывая направление деформации |
| Безопасное ядро | Центральная область остаётся свободной; поля не возникают под игроком и не перекрывают арену целиком |
| Ворота | Сегменты разделены постоянными проходами, ширина которых меняется, но маршруты сохраняются |
| Коллизии | Поля непроходимы для игрока, врагов и снарядов; при касании движение скользит вдоль края |

### Dark Zone

Dark Zone остаётся в игре как отдельная опасность, но одновременно активна только одна зона: она наносит 5 HP урона в секунду и замедляет врагов до 65% скорости.

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Автоатака — сканер ищет ближайшую цель
