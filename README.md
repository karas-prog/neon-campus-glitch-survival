# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.5.1 — Reactive Neon Ambience

Атриум стал заметно живее: визуальная среда теперь реагирует на происходящее, но не добавляет новых угроз или скрытых штрафов.

| Эффект | Как выглядит |
|---|---|
| Неоновые искры | 62 независимые световые точки дрейфуют на фоне и мигают бирюзовым, пурпурным, оранжевым, жёлтым и зелёным светом |
| Маяки Lock Fields | Яркие маркеры бегут вдоль внутренней границы каждого периметрного ограждения |
| Электрические вспышки | Редкие крестовые разряды и пурпурное свечение появляются на активных полях |
| Контур арены | По границе карты движутся сегментированные голубые огни |
| Dark Zone | Активная зона содержит дрожащие фиолетовые частицы, лучше показывающие её опасную область |
| Свет объектов | Игрок, враги, снаряды и XP-кристаллы получили мягкое неоновое свечение |

Также исправлено отображение карточек улучшений после получения уровня.

## Предыдущая механика: Breathing Edge Lock Fields

Шесть сегментов по верхнему, нижнему и боковым краям занимают примерно 28–40% арены, медленно растут, сжимаются и меняют форму. Центральная область остаётся свободной.

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Автоатака — сканер ищет ближайшую цель
