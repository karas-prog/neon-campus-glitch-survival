# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.4.1 — Arena Distortions

Атриум теперь меняет геометрию прямо во время забега. На карте появляются две временные глитч-деформации.

| Деформация | Фазы | Эффект |
|---|---|---|
| Dark Zone | Предупреждение → активна 6 сек. → распад | Игрок получает 5 HP раз в секунду; враги замедляются до 65% скорости |
| Lock Block | Предупреждение → активен 5,8 сек. → исчезновение | Временно перекрывает проход для игрока; появляется на дистанции от игрока |

### Правила безопасности

- Перед активацией обе деформации подсвечиваются: Dark Zone — пунктирным пурпурным кругом, Lock Block — оранжевой рамкой.
- Одновременно может существовать максимум две Dark Zones и один Lock Block.
- Lock Block не появляется рядом с персонажем и не может накрыть его в момент активации.
- Блоки временные: они мигают перед исчезновением и освобождают маршрут.

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Автоатака — сканер ищет ближайшую цель
