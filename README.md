# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.1 Combat Prototype

- Движение и рывок
- Автосканер по ближайшей цели
- Скитальцы и волны
- Data Shards, опыт и уровни
- Выбор модулей прокачки
- Мини-босс: Деканат-Протокол на волне 5
- Финал забега после победы

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Атака автоматическая

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
