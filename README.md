# NEON CAMPUS: GLITCH SURVIVAL



Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.3 — Campus Roles

Перед стартом забега выберите роль. Это меняет стартовые параметры и стиль прохождения.

| Роль | Стартовый набор | Подход |
|---|---|---|
| Скаут | Скорость 235, долгий рывок | Уклонение и постоянное движение |
| Куратор | 170 HP, увеличенный магнит | Выживание в плотных волнах |
| Аналитик | Урон 21, радиус 310 | Безопасная дальняя зачистка |
| Сисадмин | Два импульса, быстрая атака | Контроль множества целей |

## Campus Threats

- Скитальцы преследуют в ближнем бою
- Дроны держат дистанцию и стреляют
- Бюрократы выносливы и опасны в контакте
- Копировщики распадаются на малые цели
- Дедлайны быстры и используют снаряды
- Dean Protocol получает вторую фазу на 55% здоровья

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Автоатака — сканер ищет ближайшую цель
