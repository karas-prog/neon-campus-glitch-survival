# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.2 — Campus Threats

В игру добавлены различные паттерны угроз, снаряды противников и вторая фаза босса.

| Сущность | Поведение |
|---|---|
| Скиталец | Базовый ближний противник |
| Дрон | Держит дистанцию и стреляет импульсами |
| Бюрократ | Медленный, но прочный и опасный вблизи |
| Копировщик | После уничтожения разделяется на две малые цели |
| Дедлайн | Быстрый противник со снарядами |
| Dean Protocol | Босс на пятой волне; ускоряет залп во второй фазе |

## Основной цикл

- Движение: WASD / стрелки
- Рывок: Shift
- Автоатака: сканер ищет ближайшую цель
- Сбор Data Shards и выбор модулей после повышения уровня
- Пять волн и победа после Dean Protocol

## Публикация

В GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
