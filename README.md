# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.6.1 — Twin Boundary Waves

На арене теперь ровно две непрерывные Lock Wave: одна прилегает к верхней границе, вторая — к нижней. Обе идут через всю ширину карты и живут независимо: изгибаются, расширяются и отступают с разной фазой и скоростью.

| Элемент | Описание |
|---|---|
| Верхняя волна | Сплошной волнистый энергетический барьер по всей верхней границе |
| Нижняя волна | Независимая сплошная волна по всей нижней границе |
| Игрок | Не пересекает текущую кривую границу, но может скользить вдоль неё |
| Враги, снаряды, XP | Свободно проходят через волны без блокировки |
| Боковые зоны | Удалены: левая и правая стороны полностью открыты |
| Огоньки | Независимые случайные фоновые частицы, не связанные с барьерами |

## Dark Zone

Отдельная временная опасность: предупреждение, затем активная тёмная зона на 6 секунд. Игрок внутри получает 5 HP урона раз в секунду, а враги замедляются до 65% скорости.

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Автоатака — сканер ищет ближайшую цель
