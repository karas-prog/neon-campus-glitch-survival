# NEON CAMPUS: GLITCH SURVIVAL

Браузерный 2D survival-shooter в духе Brotato. Кампус становится ареной борьбы с цифровыми сущностями.

## v0.6.0 — Serpentine Edge Lock Zones

Прямоугольные ограждения заменены живыми периметрными зонами. Они прилегают к внешней границе арены, а их внутренняя линия непрерывно извивается, расширяется, сжимается и медленно смещается вдоль края.

| Элемент | Описание |
|---|---|
| Serpentine Lock Zones | Шесть криволинейных зон закреплены у верхней, нижней, левой и правой границ |
| Гуляющая форма | Глубина зоны строится из двух независимых синусоидальных волн и медленного дрейфа |
| Игрок | Не может пересечь текущий волнистый контур; при касании скользит вдоль него |
| Враги | Свободно проходят через Lock Zones и продолжают преследование |
| Снаряды и XP | Не блокируются периметрными зонами |
| Центральное ядро | Остаётся доступным для манёвра; зоны не телепортируются в центр |
| Огоньки | 62 независимые фоновые частицы случайно дрейфуют, меняют оттенок и периодически вспыхивают в произвольных местах |

## Dark Zone

Отдельная временная опасность: предупреждение, затем активная тёмная зона на 6 секунд. Игрок внутри получает 5 HP урона раз в секунду, а враги замедляются до 65% скорости.

## Управление

- WASD / стрелки — движение
- Shift — рывок
- Автоатака — сканер ищет ближайшую цель
